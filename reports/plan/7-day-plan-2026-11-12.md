## 6. Payout setup checklist (do it yourself)

**X (do Friday):**
1. x.com → More → Monetization / Creator Studio → Original Content Rewards.
2. Choose **Stripe** (or X Money) and start payout setup. Stripe will ask for your legal name, address, date of birth, US tax info (SSN / W-9) and a bank account. Type these in yourself; never paste them into a chat.
3. Keep Premium active (it's a requirement you already meet).
4. Check the eligibility page every Thursday and write down verified followers + verified impressions.
5. Once eligible: payouts every 2 weeks, $30 minimum.

**Facebook:**
1. Professional dashboard → Monetization → see what you're eligible for (Content Monetization is invite-only).
2. Keep professional mode on; post only original/voiced reels so you qualify if invited.
3. If invited: set up the payout account with tax info and bank inside Meta's payout settings.

**YouTube (@jasejoker):**
1. Turn on 2-Step Verification on the Google account.
2. Studio → Earn → "Get notified" when eligible.
3. When eligible: link an AdSense account during the application (tax info + bank there).
4. Expect a reused-content review: originals and voiced edits only from now on.
