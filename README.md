# Social Media Analyzer Skill

A skill for diagnosing YouTube Shorts performance issues, X/Twitter follower origins, and multi-platform growth patterns.

## Purpose

Built from real analysis of uneven YouTube Shorts views (1 view vs thousands), engaged view metrics, the October 2026 Shorts originality update, and X/Twitter follower source questions.

## Files

- `SKILL.md` — Main instructions for the agent
- `evals/` — Test cases and trigger phrases
- `CHANGELOG.md` — Version history

## How to use with Claude (or similar)

1. Clone or download this repo
2. Point your agent at the `SKILL.md` file when analyzing social media performance
3. Or add the skill directory to your agent's skills folder

## Example triggers

- "My YouTube Short only has 1 engaged view at 100%"
- "Why do some Shorts get thousands of views and others get nothing?"
- "Where did my new Twitter followers come from?"
- "Analyze my YouTube channel / Shorts performance"

## Key insights covered

- Shown in feed vs engaged views vs public views
- Seed audience testing behavior
- October 2026 originality update impact on clip/meme channels
- CapCut uploads are not the cause of selective low views
- Private follower lists cannot be accessed externally
